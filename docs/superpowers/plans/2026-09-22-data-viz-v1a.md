# Data + Data Viz V1A / CSV Cleaner and Chart Builder Implementation Plan

**Goal:** ส่งมอบ product แรกของสาย Data ที่รับ CSV แบบมี schema, ทำความสะอาดข้อมูลแบบ deterministic, aggregate ตาม chart spec และสร้าง cleaned CSV + SVG chart + report ที่ตรวจ lineage และ replay ได้

**Architecture:** CSV text → parsed rows → validated `DatasetIR` → allowlisted transforms → typed aggregation → `ChartIR` → cleaned CSV/SVG/report → reopen/content QA → idempotent manifest. ไม่มี LLM ในเส้นทางมาตรฐาน; semantic column mapping เป็น optional capability ภายหลัง

**Scope:** ทำใน `main` ภายใต้ `packages/data-production-ir` และ `services/data-production-api`; ไม่แก้ Video, Graphics, Spreadsheet หรือไฟล์งานที่มีการแก้ไขอยู่ก่อนแล้วนอกขอบเขตนี้

## Acceptance gates

- schema และ typed values ตรวจได้ก่อน transform; unknown/missing columns และ malformed rows ต้อง reject พร้อม path ที่แก้ได้
- transforms จำกัดอยู่ใน allowlist (`trim_text`, `fill_null`, `filter_equals`, `sort_by`) และทำซ้ำได้ผลเดิม
- chart รองรับ `bar` และ `line` พร้อม `sum`, `count`, `avg`; aggregate ต้องตรงกับ dataset ที่ถูก normalize แล้ว
- output มี cleaned CSV, SVG chart และ JSON report พร้อม source lineage และ transform log
- SVG ห้ามมี script, external reference หรือ unescaped user markup; reopen QA ต้องอ่าน artifact กลับได้
- idempotency key เดิม + input เดิม replay โดยไม่เขียน artifact ซ้ำ; key เดิม + input ต่างต้อง conflict
- synthetic benchmark 20 งาน: totals/row counts/lineage ตรงทุกเคส, zero model calls, invalid fixtures reject ตามคาด

## Task 1 — Contract, parser และ DatasetIR — complete

**Create:** `packages/data-production-ir/pyproject.toml`, `data_ir/models.py`, `data_ir/validation.py`, package tests

- เพิ่ม `ColumnSpec`, `TransformSpec`, `ChartSpec`, `DatasetRequest`, `DatasetIR`, `ChartIR`, `ArtifactRef`, `ValidationIssue`
- parse CSV ด้วย stdlib `csv`; รองรับ delimiter ที่จำกัดและ header ที่ไม่ซ้ำ
- explicit mapping ใช้ `source_name`; ถ้าไม่ส่ง schema ให้ infer ชนิดแบบ deterministic จากค่าทั้งคอลัมน์
- typed values รองรับ text, integer, decimal, date, boolean, null และไม่แปลง formula-like text เป็น executable content
- เพิ่ม tests สำหรับ quoted commas, Thai text, decimal/date/null, missing/unknown columns, duplicate headers และ invalid types

## Task 2 — Deterministic transforms และ chart aggregation — complete

**Create:** `services/data-production-api/pyproject.toml`, `data_production/recipe.py`, `data_production/aggregation.py`, tests

- normalize CSV เป็น `DatasetIR` พร้อม row/column lineage และ transform log
- ใช้ transforms allowlist เท่านั้น; ห้าม eval, SQL จาก input หรือ network fetch
- aggregate ตาม `ChartSpec` ด้วย `Decimal`; count นับ non-null numeric/text ตามสัญญา และ avg ห้ามหารศูนย์
- reject missing chart columns, non-numeric sum/avg และ empty post-filter dataset อย่างชัดเจน
- tests ต้องพิสูจน์ aggregate ใช้ค่าหลัง trim/fill/filter/sort และ lineage ไม่หาย

## Task 3 — Output renderer และ reopen QA — complete

**Create:** `data_production/render.py`, `data_production/qa.py`, renderer tests

- เขียน cleaned CSV แบบ stable ordering/decimal/date format
- สร้าง SVG bar/line จาก `ChartIR` ด้วย geometry deterministic, escaped labels, แกนที่มี tick values/labels/หน่วย และ bounded dimensions
- สร้าง JSON report ที่มี row count, null counts, aggregates, schema, axis labels/units, lineage summary และ `model_calls=0`
- reopen CSV/SVG/report และตรวจ totals, chart point count, no-script/no-external-ref, artifact hashes

## Task 4 — Replay-safe job, API และ CLI — complete

**Create:** `data_production/jobs.py`, `main.py`, `cli.py`, `telemetry.py`, API/job/CLI tests

- `run_data_job` เขียน output ผ่าน temporary files แล้ว publish manifest หลัง QA ผ่าน
- map invalid request → 422, idempotency conflict → 409, accepted result → 201
- API `/v1/data/jobs`, health endpoint และ CLI `build --input --output --idempotency-key`
- replay result คืน artifact references เดิมและ `bytes_written=0`, `model_calls=0`

## Task 5 — Benchmark และ documentation — complete

**Create:** `scripts/benchmark.py`, `tests/fixtures/datasets_20.json`, benchmark tests, README

- fixtures 20 งานผสมภาษาไทย/อังกฤษ, null/date/decimal, transforms, bar/line และ invalid boundary cases
- benchmark รายงาน accepted/rejected, aggregation mismatches, reopen failures, model calls และ bytes
- update `services/README.md` และ mark this plan complete

## Readiness hardening — complete

- inferred schemas preserve Unicode/space headers and map generated keys to the
  correct CSV positions
- leading-zero integer-looking values remain text; CSV input is capped at
  10,000 data rows
- replay validates artifact path, byte size, and SHA-256 before returning an
  accepted result
- per-key lock serializes duplicate local processes and the benchmark refuses
  a non-empty output directory instead of deleting prior evidence
