# Web V1A / Template Landing Builder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ส่งมอบ Template Landing Builder รุ่นแรกที่รับ page spec แบบมีโครงสร้าง สร้าง static HTML/CSS ที่ตรวจ responsive/accessibility ได้ และเรียกซ้ำได้ปลอดภัยโดยไม่เรียก LLM หรือ network

**Architecture:** structured page request → validated PageIR → fixed landing template → deterministic HTML/CSS renderer → build/accessibility QA → artifact manifest → idempotent replay. V1A ไม่รับ arbitrary HTML/JS, ไม่ fetch external assets, ไม่ deploy และไม่มี model adapter ในเส้นทางมาตรฐาน

**Tech Stack:** Python 3.11+, Pydantic v2, FastAPI, stdlib HTML escaping/hashlib/pathlib, pytest, Ruff, mypy

**Spec:** `docs/superpowers/specs/2026-09-22-logic-first-production-platform-design.md` และ `docs/superpowers/plans/2026-09-22-production-platform-next-products.md`

## Global Constraints

- V1A รับเฉพาะ structured input; `model_calls=0`
- template จำกัดเป็น `landing-v1`; ไม่รับ raw HTML, inline script หรือ external stylesheet/font/image
- link ต้องเป็น relative path, fragment หรือ `mailto:`; reject `javascript:`, `data:`, `http://`, `https://`
- output ต้องมี HTML, CSS, content hash, recipe/schema versions และ QA evidence
- replay ตรวจ manifest schema/key/status, artifact path, byte size และ SHA-256 ก่อนคืน accepted

## Review Focus

- user text containing HTML/script-like characters must be escaped as text
- unsafe links and raw HTML fields must reject before writing artifacts
- empty headings, invalid slugs, too many features and missing CTA labels must return actionable issues
- output must include viewport metadata, landmarks, one h1, keyboard-visible links, and no external references
- a tampered HTML/CSS artifact or manifest must never be accepted as replay
